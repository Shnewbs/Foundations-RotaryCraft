# Legacy renderer and animation audit

Scope: compare the legacy tick/render path for every machine ported by 1.0.0 with the current block/item models. This is a visual-animation audit, not a claim of full gameplay or model-shape parity. The 1.1.0 changes restore missing resource references and the visibly missing Fan rotor turn; larger renderer and custom-mesh ports remain follow-up work.

| Machine | Legacy implementation and renderer behavior | 1.1.0 status |
| --- | --- | --- |
| Fan | `TileEntities/Farming/TileEntityFan.java` advances `phi` from rotational speed (`omega`); `Renders/DM/RenderFan.java` passes `-tile.phi` to `ModelFan` and draws translucent airflow/harvest bounds. | **Rotor restored:** active blockstate uses an eight-frame rotor sheet at one frame per game tick; idle and inventory use a static rotor. The FE-powered port has no mechanical `omega`, so the animation is a constant-speed active indicator rather than legacy speed-linked motion. Follow up with speed-linked animation, custom mesh fidelity, and the legacy airflow/harvest overlays if that fidelity is brought forward. |
| Grindstone | `TileEntities/TileEntityGrindstone.java` advances `phi` from `omega`; `Renders/DMI/RenderGrindstone.java` rotates `ModelGrindstone` by `tile.phi` and renders the held input item separately. | **Follow-up:** current cube model is static; restore the custom mesh, rotating wheel, and rendered input/tool presentation. |
| Winder | `TileEntities/TileEntityWinder.java` advances `phi` from `omega`; `Renders/DMI/RenderWinder.java` rotates `ModelWinder` and selects a spring/coil model variant from its inventory. | **Follow-up:** current model is static; restore the custom mesh, rotating component, and coil-dependent visual. |
| Blower | `TileEntities/TileEntityBlower.java` has an empty `animateWithTick`; no dedicated custom renderer/model animation for the Blower was found under `Renders`. | No legacy renderer-driven motion found; current block/item textures are static. |
| DecoTank | `TileEntities/TileEntityDecoTank.java` has an empty `animateWithTick`; no dedicated custom renderer was found under `Renders`. | No legacy renderer-driven motion found; current tank texture is static. Fluid-surface/model fidelity is separate from animation. |
| Player Detector | `Renders/M/RenderDetector.java` draws the custom `ModelDetector` without a time/rotation parameter; `TileEntities/TileEntityPlayerDetector.java` has an empty `animateWithTick`. | No renderer-driven animation found; restore the original custom mesh as separate model-shape follow-up work. |
| Smoke Detector | `Renders/MI/RenderSmokeDetector.java` draws the custom `ModelSmokeDetector` without a time/rotation parameter; `TileEntities/TileEntitySmokeDetector.java` has an empty `animateWithTick`. | No renderer-driven animation found; the 1.1.0 model/texture references are restored, while custom mesh fidelity remains follow-up work. |
| Item Cannon | `Renders/MI/RenderItemCannon.java` draws the custom `ModelItemCannon` without a time/rotation parameter; `TileEntities/TileEntityItemCannon.java` has an empty `animateWithTick`. | No renderer-driven animation found; restore the original custom mesh as separate model-shape follow-up work. |
| Sorting | `TileEntities/TileEntitySorting.java` has an empty `animateWithTick`; no dedicated custom renderer was found under `Renders`. | No legacy renderer-driven motion found; current block/item models are static. |
| Mob Harvester | `Renders/M/RenderHarvester.java` draws the custom static `ModelHarvester`, then renders an `iotick`-pulsed range box and a red targeting laser when `harv.laser` is true. Its `animateWithTick` is empty. | **Follow-up:** current active block model indicates targeting, but does not recreate the custom mesh, pulsing range box, or laser. |
| Defoliator | `TileEntities/World/TileEntityDefoliator.java` advances `phi` from `omega`; `Renders/MI/RenderDefoliator.java` passes `-tile.phi` to `ModelDefoliator`. | **Follow-up:** current active blockstate changes its static texture only; restore the custom mesh and rotating model component. |
| Item Refresher | `TileEntities/TileEntityItemRefresher.java` has an empty `animateWithTick`; no dedicated custom renderer was found under `Renders`. | No legacy renderer-driven motion found; current block/item models are static. |

The three legacy shaft-driven model rotations still outstanding are Grindstone, Winder, and Defoliator. The Mob Harvester's animated targeting overlays and the Fan's speed/overlay fidelity are also follow-ups. Original custom mesh shapes for Grindstone, Winder, Player Detector, Smoke Detector, Item Cannon, Mob Harvester, and Defoliator remain separate visual-fidelity work. Other machines in this audit did not show a tick-driven custom-render animation in their legacy renderer/tick hooks.
